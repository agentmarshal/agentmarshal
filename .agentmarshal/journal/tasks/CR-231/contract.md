# OpenSpec 1.15.0

## Context

The operator decided on 2026-10-24 to raise OpenSpec in 0.6.0 (the
environment check reports 1.15.0 against the pinned 1.13.2). 1.13.2
refuses a delta that changes only `## Purpose` and ignores a delta Purpose
on a spec that already has one, which left the extension-stages Purpose
stale (CR-226 dropped that part). The pin lives in the extension manifest
(ADR-0013 decision 12 as amended: raising the pin is an extension release).

## Objective

The repository runs on OpenSpec 1.15.0 and the extension-stages Purpose
says what the capability does now.

## Acceptance Criteria

As in the header.

## Non-Goals

- Code changes; changing any requirement.
- The coordinator's own frames and tooling (updated outside this
  repository).
