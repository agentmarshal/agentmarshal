`readme-name-not-scanned`: в `src/agentmarshal/outbox.py:349` README отбрасывается через `continue` до вызова `_name_hits`, поэтому его имя не сканируется — а `design.md` в решении «The file name is scanned too» утверждает «This holds for every entry, draft or not». Контракт README из проверки выводит, так что AC не нарушен, но маркер, являющийся подстрокой `README.md`, прошёл бы молча.

`captureerror-text-printed`: в `src/agentmarshal/outbox.py:326` ветка `CaptureError` печатает `{error}` напрямую, тогда как решение design.md гласит «no exception's text is printed». Текст `private_markers_from_project` путей не несёт (я проверил все четыре сообщения в `capture.py:685-702`), так что утечки пути нет, но одно из сообщений дословно echo-ит неизвестные ключи секции `leak_scan` — то есть абсолютное правило design'а код не держит.

`draft-number-reuse-on-date-shaped-slug`: `_DRAFT_NAME` (`src/agentmarshal/outbox.py:58`) отбрасывает имя с `-NN-NN-` сразу после номера, и это касается не только рукописных дат — gist «12 34 widget» даёт `0001-12-34-widget.md`, который счётчик не видит, так что следующий `new` снова выдаст `0001-…`. Перезаписи нет (`O_EXCL`), но «named with the next free number» и «name order stays creation order» в этом случае не держатся, а design.md называет цену нулевой.

`untested-signature-named-file`: ветка `scan_for_leaks(name)` в `_name_hits` (`src/agentmarshal/outbox.py:279`) не покрыта ни одним тестом — оба теста про имена (`tests/test_outbox.py`, сценарии «a name that carries a secret…» и «a file name that carries a secret…») используют только configured marker, хотя контракт говорит «carries a configured marker **or** matches a signature». Там же не покрыты ветки `CaptureError`/`GateError` в `_run_check:325-333` и весь `_config_error_text`.

`duplicated-marker-identification`: литерал `f"private-marker #{index}"` и цикл перечисления маркеров написаны заново дважды в `src/agentmarshal/outbox.py:281` и `:301` (и третий раз живут в `capture.py:663`), причём `_draft_hits` — это ровно `_name_hits` плюс те же два скана по `text`. Общий helper `(_scan(safe_name, haystack, markers))` убрал бы дублирование и подкрепил бы тезис design.md «there is nothing to drift», который в текущем виде неточен: формат идентификации маркера скопирован, а не переиспользован.
