### Advisory

`016-kept-at-claim-broader-than-mechanism` — in `docs/proposals/016-reviewer-prose-not-durable-in-the-published-release.md` the disposition states "There is no kept-at path there any more". On the default branch `_preserve_output` and `_reject` (`src/agentmarshal/journal/review.py:214-238`) still write the reviewer's raw output to a temporary file and print "reviewer output kept at …" whenever a verdict fails to parse or fails record validation. The intended claim — that the *successful* path no longer uses a temporary file — is true and is confirmed by `submit_review.py:73` pinning prose unconditionally; the sentence as written is broader than the mechanism it describes, in a public document whose own subject is documentation that overstates what the tool does.

`020-self-attribution-overstated-no-private-markers-configured` — `docs/proposals/020-leak-scan-names-no-file-and-self-matches.md` says "this project now pins reviewer prose as journal evidence, so we have acquired exactly the shape the reporter describes", and `docs/proposals/README.md:81-82` lists 020 among "defects this project also has in its own repository". The reporter's own framing needs both conditions: diffs captured as evidence *and* markers declared in the versioned config. Markers come from `leak_scan.private_markers` in `project.json` (`gate.py:493-515`), and this repository's `.agentmarshal/project.json` carries no `leak_scan` key at all, so the self-match cannot currently fire here. Only half the precondition is met; "exactly the shape" and the four-way list overstate it.

`partial-disposition-not-in-documented-vocabulary` — `docs/proposals/README.md:30-34` enumerates the disposition vocabulary as accepted / deferred / declined, and `CONTRIBUTING.md:53-54` repeats it as "(accepted, declined, deferred)". A reporter following the new tracking section to read their disposition finds a value the documented vocabulary does not contain.
