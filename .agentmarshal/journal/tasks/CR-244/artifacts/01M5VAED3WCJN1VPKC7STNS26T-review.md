## Findings

**B-THREAT-FINDINGS-COMPLETION-LINE** (blocking, claim-accuracy) — `docs/threat-model.md:327-332`: в предложении про findings-lane completion процитированы строки `Placement: sidecar` ahead of `gate: findings passed` and `completed through findings`, но `agentmarshal complete --findings` строку `gate: findings passed` не печатает никогда. Эта строка есть ровно в одном месте — `src/agentmarshal/cli.py:950`, в ветке `gate --findings`; путь completion (`cli.py:1076-1078`, `1202-1206`) печатает `Placement: sidecar`, затем строки отчёта, путь записи и `completed through findings`. Абзац — ровно тот, который AC4 требует «quotes the lines the tool prints», поэтому неверно атрибутированная строка здесь попадает в сам критерий.

**A-HARNESS-EXTENSION-CLASSIFIED-LOCAL-STATE** (advisory, claim-accuracy) — `docs/harness-setup.md:80-84`: `extension` отнесён к «the commands that write the local state», но `agentmarshal extension switch off` открывает задачу через `open_task` и атомарно перезаписывает **закоммиченный** `.agentmarshal/switches.toml` (`src/agentmarshal/switch_off.py:1-11`, регистрация в `src/agentmarshal/extension_trust.py:135,168-174`) — то есть пишет journal, а не только local state. В том же перечислении `init` и `outbox` названы «journal writers», хотя ни один не пишет record (`init` → `.agentmarshal/project.json` + `upstream/`, `outbox` → `.agentmarshal/upstream/`). Сам вывод («это команды оператора, не implementer'а») верен, неверны подписи групп. В `docs/templates/claude-code-settings.local.json:3` формулировка объединённая («write the journal or the local state, run extension code or delete branches») и потому точная.
